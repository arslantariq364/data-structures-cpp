# Core Data Structures & Algorithms in C++

Coursework implementations of AVL trees, BSTs, singly/doubly linked lists, queues, stacks and recursive exercises.

## Explore

```bash
git clone https://github.com/arslantariq364/data-structures-cpp.git
cd data-structures-cpp
```

The source files collect exercises, including commented alternatives. Inspect the desired exercise and its entry point before compiling; these files are not one unified library or build target.

The repository demonstrates foundational algorithms and pointer-based implementations. It does not provide verified graph/heap/hash-table implementations, custom allocators, cache-locality benchmarks, or a container correctness guarantee. No production-quality or benchmark claim is made.
